# 1007-People-with-Occlusion-and-Multi-pose-Face-Recognition-Data


## Description
This dataset contains 1,007 people with 200 images per subject, totaling 201,400 images. Each subject was captured under 4 kinds of light conditions, 10 kinds of occlusion cases (including non-occluded case) and 5 kinds of face poses. This data can be applied to computer vision tasks such as occluded face detection, recognition, and pose-invariant face recognition tasks.

For more details, please refer to the link: https://www.nexdata.ai/datasets/computervision/1073?source=Github


## Data size
1,007 people, 200 images per person

ranging from teenager to the elderly, the middle-aged and young people are the majorities
## Collecting environment
including indoor and outdoor scenes
## Data diversity
multiple face poses, multiple occlusion cases, multiple ages, multiple light conditions and scenes
## Device
cellphone
## Data format
.jpg
## Accuracy
the accuracy of labels of face pose, occlusion case, gender and age is more than 97%
